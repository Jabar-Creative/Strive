Laporan verifikasi end-to-end item RT-02 (Dev B). Dikerjakan 18 Okt 2026 (sesi susulan minggu 12–16 Okt).

Lingkungan: lokal (web :3000 · API :3001 + gateway WS · PostgreSQL/Redis Docker) Status: seluruh skenario lulus Tanggal: 2026-10-18

1 · Ringkasan

Layar squad kini memakai hook useRealtime: mesin transport Q-05 (WS + polling 30 dtk) teruji di lib/leaderboard-live dipasang lewat hook yang bisa dipakai layar mana pun — squadId terisi berarti kanal WS squad, null berarti polling-murni (kanal user:/league: memang polling di v0.1, PRD E15). Penjaga refetch in-flight + satu trailing run yang tadinya closure privat squad-screen diangkat menjadi fungsi murni teruji lib/refetch-guard.

5 · Keputusan teknis

  • WS "dimatikan" dari sudut klien (rute di-abort di browser): RT-02 item KLIEN; perilaku server saat WS mati adalah milik RT-01 (sudah dibuktikan Dev A). FEATURE_WS_ENABLED hanya komentar di fitur.ts — kill switch yang benar-benar dibangun hanya FEATURE_TOPUP_ENABLED (P-02), jadi tidak ada cara lain mematikan WS tanpa mematikan REST yang seproses.
  • Penyegaran polling dibuktikan lewat jalur rebuild milik aplikasi: ubah poin di Postgres + buang kunci ZSET → poll berikutnya memicu rebuildSquad (bukan menulis Redis manual).
  • Hook memasang mesin sejak squadId null: panggilan ambil saat null no-op terjaga; transisi null → id tidak memasang ulang mesin.
